# Context

Start here before changing Sinapsi. The files in this directory summarize the
package from several engineering perspectives.

- [`product.md`](./product.md): purpose, consumers, and public surface.
- [`architecture.md`](./architecture.md): module boundaries and runtime flow.
- [`graph-and-activation.md`](./graph-and-activation.md): topology, palette, motion, and activation semantics.
- [`testing.md`](./testing.md): confidence model and test boundaries.
- [`release.md`](./release.md): package payload and release gate.

Context documents describe the current system. Architectural commitments belong
in ADRs, mandatory constraints belong in rules, and individual changes belong
in specifications.
